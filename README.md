# aguitechcore_api - sxxysecret.com Node/Express + MongoDB API

Backend de sxxysecret.com (Node 20 + Express 4 + Mongoose 8 + JWT + AuditLog).

Endpoints: /api/auth, /api/users, /api/projects, /api/tasks, /api/clients,
/api/blog, /api/chat, /api/dashboard, /api/mcp, /api/appointments, etc.

Repos relacionados:
- aguitech/aguitechcore_frontend - React/Vite client
- aguitech/aguitechcore_bd - Dump MongoDB sanitizado

Run: cd server && npm install && node src/index.js
